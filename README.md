# エンタメタイプ診断

9問・1分半で「楽しみ方」を8タイプに分け、まだ試していないエンタメジャンルを推薦する診断サイトです。

- `index.html` 1ファイルで動きます。ダブルクリックしてブラウザで開くか、そのまま静的ホスティングに置いてください。
- 外部ライブラリ・サーバー通信・解析タグ・個人情報の取得はありません。回答は画面を閉じると消えます（保存しません）。

## 編集する場所

診断の中身はすべて、`index.html` の冒頭にある次のブロックにまとまっています。

```html
<script id="quiz-data" type="application/json">
{ ... }
</script>
```

ここは **JSON** です。編集するときは次の点に気をつけてください。

- 文字列は `"ダブルクオート"` で囲む
- 項目の間はカンマ `,` で区切り、**最後の項目の後ろにはカンマを付けない**
- コメント（`//` や `/* */`）は書けない
- 文章の中で「」を使うのはOK。`"` を使いたいときは `\"` と書く

編集後はブラウザで開き直して確認してください。JSONが壊れていると画面が真っ白になります（開発者ツールのコンソールにエラーが出ます）。

## 1. 全体設定 `meta`

| キー | 内容 |
|---|---|
| `title` | サイト名 |
| `lead` | トップページの説明文 |
| `hashtag` | シェア時のハッシュタグ（`#` なし） |
| `duration` | 「9問・1分半」の表記。ボタンなどに使われます |

## 2. 軸 `axes`

3本の軸と、それぞれの両端（`sides`）を定義しています。並び順が **タイプコードの文字の順番**（場→人→対象）になります。

```json
{
  "id": "place",
  "name": "場",
  "sides": [
    { "code": "L", "label": "現場", "desc": "その場の空気を味わう" },
    { "code": "W", "label": "作品", "desc": "作品そのものを味わう" }
  ]
}
```

`label` や `desc` の文言は自由に変えて大丈夫です。`code`（L/W など）を変える場合は、質問の `value` とタイプのキー（`LIE` など）もすべて合わせて変更してください。

## 3. 質問 `questions`

上から順に出題されます。軸ごとに固まらないよう、並びを混ぜてあります。

```json
{
  "axis": "people",
  "text": "終わった直後、どっち？",
  "a": { "text": "誰かに感想を送る", "value": "S" },
  "b": { "text": "一人で余韻に浸る", "value": "I" }
}
```

| キー | 内容 |
|---|---|
| `axis` | どの軸の質問か（`place` / `people` / `target`） |
| `text` | 質問文 |
| `a` / `b` | 選択肢。`text` が表示文、`value` が加点される文字 |

ルール：

- **各軸の質問数は奇数（今は3問ずつ）** にしてください。偶数だと同点が起こります（同点時は `sides` の1つ目が選ばれます）。偶数になるとコンソールに警告が出ます。
- `a` と `b` の `value` は、その軸の2つの `code` を1つずつ使います。どちらが A でも構いません（偏らないよう混ぜてあります）。
- 質問文にジャンル名（ロック、演劇など）は入れず、どちらが「正解」か分からない書き方にしてください。
- 1問10秒以内で読める長さが目安です。

## 4. タイプ `types`

キーが3文字コード（`LIE` など）です。8つすべて必要です。

```json
"LSE": {
  "name": "仲間型",
  "nickname": "終演後すぐ感想を送る人",
  "color": "#E8590C",
  "illust": "bubble",
  "summary": "誰かと一緒に行って感想を言い合うのが楽しい。",
  "description": "（3文以内のタイプ説明）",
  "reason": "（「いつものジャンルを好きな理由」2文）",
  "genres": [ ... ],
  "events": [ ... ]
}
```

| キー | 内容 |
|---|---|
| `name` | タイプ名。結果画面のいちばん上に大きく表示されます |
| `nickname` | 二つ名。**現在は画面に表示していません**（データだけ残しています） |
| `color` | テーマカラー（`#RRGGBB`）。結果画面全体・イラスト・一覧の色線に反映されます。ボタンの文字色（白/黒）は自動で決まります |
| `illust` | イラストの小物。`hands-up` / `bubble` / `penlight` / `stamp` / `headphones` / `glasses` / `flag` / `magnifier` から選択 |
| `summary` | 短い説明（8タイプ一覧と結果画面のイラスト下に表示） |
| `description` | タイプの説明（3文以内） |
| `reason` | 「あなたがいつものジャンルを好きなのは、たぶんこの理由」の本文（2文） |

### 推薦ジャンル `genres`

先頭から **3つ** 表示されます。

```json
{ "name": "寄席・お笑い", "category": "演劇", "why": "笑ったポイントの違いで、帰り道の会話がいちばん盛り上がるから。" }
```

- `name`：ジャンル名（下の「ジャンルの範囲と出典」の小ジャンル名を使う）
- `category`：大ジャンル名（ジャンル名の上に小さく表示）
- `why`：なぜこのタイプに合うか（1文）

### 公演カード `events`

先頭から **最大3枚**（最低2枚は入れてください）表示されます。現在はダミーデータです。

```json
{
  "title": "サンプル公演A",
  "genre": "寄席・お笑い",
  "date": "2026年11月28日（土）",
  "venue": "サンプルホール",
  "price": "3,000円"
}
```

すべて表示用の文字列なので、日付や価格は見せたい形のまま書いてください。

## 5. 一覧の並び順 `typeOrder`

トップのキャラクター並びと「8タイプ一覧」の表示順です。

## ページ構成（URL）

| URL | 画面 |
|---|---|
| `#/` | トップ |
| `#/quiz` | 質問（選ぶと自動で次へ） |
| `#/result` | 結果（9問すべて回答していないと開けず、トップに戻ります） |
| `#/types` | 8タイプ一覧 |
| `#/types/LSE` | タイプ詳細（診断なしで閲覧用。軸の比率は出ません） |
| `#/me` | マイページ（プロフィールカード・開拓タイプ・体験実績・ステッカー帳・ポイント履歴） |
| `#/missions` | ミッション一覧とポイントのため方 |
| `#/genres` | ジャンル図鑑（「気になる」「体験した」「友達に勧める」） |
| `#/shop` | ポイント交換所 |

## シェア

- 「結果をコピー」：タイプ名・推薦ジャンル・ハッシュタグをクリップボードにコピー
- 「Xでポスト」：X の投稿画面（intent リンク）を開きます。サイトを http(s) で公開している場合はURLも付きます

## マイページ機能（ポイント・ミッション・実績）

設定はすべて JSON の `genreCatalog` と `game` にあります。

### 仕組みと制約

- 記録はブラウザの **localStorage（この端末だけ）** に保存します。サーバーには送りません。別の端末やブラウザとは共有されず、ブラウザのデータを消すと消えます。
- 「体験した」は**自己申告**です（バックエンドがないので、来場の確認はできません）。本番で特典を実際に渡すには、チケット購入履歴との連携などサーバー側の仕組みが必要です。
- 交換所の「会場ドリンク引換券」「抽選確率アップ」は**デモ**です。公開サイトで実在の特典と誤解されないよう、会場名は入れていません。

### 記録されること

| 操作 | どこで |
|---|---|
| 診断 | 結果画面を開いたとき |
| 未開拓ジャンルをチェック | ジャンル図鑑で項目を開いたとき（体験済みジャンルは数えない） |
| 気になる登録 | 結果画面・ジャンル図鑑の「＋ 気になる」 |
| ジャンル体験 | 結果画面・ジャンル図鑑の「体験した」（何回でも押せる） |
| シェア | 結果・プロフィールのコピー／X |
| 友達に紹介 | ジャンル図鑑の「友達に勧める」（紹介文をコピー） |

### ポイントの相場（初期値・案）

`game.pointRules` で変えられます。`limit` は `once`（初回のみ）／`perGenre`（ジャンルごとに1回）／`daily`（1日1回）／`none`（毎回）。

| 行動 | pt | 回数 |
|---|---|---|
| 診断 | 20 | 初回のみ |
| 未開拓ジャンルをチェック | 2 | ジャンルごと |
| 気になる登録 | 5 | ジャンルごと |
| ジャンル体験 | 30 | ジャンルごと |
| シェア | 5 | 1日1回 |
| 友達に紹介 | 10 | ジャンルごと |
| ミッション達成 | 10〜100 | ミッションごと |
| 実績解除 | 10〜50 | 実績ごと |

| 交換品 | pt |
|---|---|
| 電子ステッカー | 50 |
| 着せ替え | 100 |
| 称号 | 150 |
| 抽選確率アップ（デモ） | 200 |
| 会場ドリンク引換券（デモ） | 300 |

考え方：**新しいジャンルを1四半期に2〜3回体験すると、ドリンク1杯分（300pt）に届く**くらいに設定しています。体験1回で「ジャンル体験30pt＋常設ミッション50pt」が入るので、行動を最も強く後押しするのは「体験」です。シェアや閲覧は小さく、1日1回やジャンルごと1回に制限して、連打で稼げないようにしています。

### 開拓タイプ（称号） `game.exploreTitles`

ジャンルの状態に応じて自動で増えます。上から順に判定し、各ジャンルで最初に当てはまったものが付きます。`{genre}` はジャンル名に置き換わります。

```json
{ "when": "experience", "count": 3, "label": "{genre}通" },
{ "when": "experience", "count": 1, "label": "{genre}デビュー済み" },
{ "when": "interest", "label": "{genre}開拓中" }
```

### ミッション `game.missions`

```json
{
  "id": "2026q4-event", "kind": "regular", "from": "2026-10-01", "to": "2026-12-31",
  "title": "イベントに1つ参加しよう",
  "goal": { "type": "experience", "count": 1 },
  "reward": { "points": 50, "sticker": "mic" }
}
```

| キー | 内容 |
|---|---|
| `id` | 重複しない文字列。**四半期ごとに更新するときは新しいidにする**（同じidだと達成済みのまま） |
| `kind` | `regular`（常設・四半期更新）／`season`（季節）／`collab`（コラボ）。表示名は `game.missionKinds` |
| `from` / `to` | 表示・集計する期間（その日を含む）。期間外のミッションは自動で表示されない |
| `partner` | コラボ相手の表示名（任意） |
| `goal.type` | `diagnose`／`view`／`interest`／`experience`／`share`（結果・プロフィール両方）／`shareProfile`／`introduce` |
| `goal.count` | 必要な回数 |
| `goal.unique` | `true` なら同じジャンルを重ねて数えない |
| `goal.categories` / `goal.genres` | 対象を大ジャンル／ジャンルに絞る（季節・コラボ用） |
| `reward` | `points`／`sticker`（ステッカーid）／`title`（称号）／`skin`（着せ替えid） |

期間内の行動だけが数えられるので、新しい四半期のミッションは0からスタートします。

### 体験実績 `game.achievements`

条件を満たすと自動で解除され、バッジになります。`cond.type` は次のいずれか。

`diagnose`（診断回数）／`interestedGenres`／`experiencedGenres`／`experiencedCategories`（体験した大ジャンル数）／`introducedGenres`／`viewedGenres`

### ステッカー・着せ替え・交換所

- `game.stickers`：`id`・`name`・`color`。絵柄は `index.html` 内の `STICKER_ART` にあり、絵柄がないidは名前の1文字目が入ります。
- `game.skins`：プロフィールカードの背景。見た目はCSSの `.skin-<id>` で定義しています。
- `game.shop`：`kind` は `sticker`／`skin`／`title`／`perk`（デモ特典。交換すると `DEMO-` で始まるコードを表示）。

### ジャンル図鑑 `genreCatalog`

チケットぴあの分類（上の「ジャンルの範囲と出典」）をそのまま入れています。各タイプの推薦ジャンルはここに含まれている必要があり、含まれていないとコンソールに警告が出ます。
